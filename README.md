This project analyzes online retail transaction data to identify meaningful customer segments and support data-driven marketing decisions. The analysis includes data cleaning, exploratory data analysis, RFM modeling, rule-based customer segmentation, K-means clustering, and churn prediction using machine learning.

The project transforms purchasing behavior into actionable customer groups such as Champions, Loyal Customers, At-Risk Customers, and Lost Customers. Each segment is evaluated based on recency, purchase frequency, and total spending, followed by targeted recommendations for customer retention, reactivation, and personalized marketing.

Technologies used: Python, pandas, NumPy, Matplotlib, scikit-learn, RFM analysis, K-means clustering, Logistic Regression, and Random Forest.
